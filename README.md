# math-mastery · 中小学数学方法融会贯通

> 纯前端、零依赖、离线可用的中小学数学方法学习与练习应用。覆盖小学到高中核心解题技巧，**每轮练习随机出题、永不重样**，让每个学生都能充分掌握学习技巧。

## 核心特性

### 参数化随机出题引擎
- 每个核心方法配备 `qgen(n)` 生成器，**第一遍、第二遍、第三遍……题干都不同**
- 正确答案由数学构造直接算出，正确性有保证
- 每个生成题自带分步解析 + SVG 配图，配图只展示「题给数据与结构关系」，绝不泄露答案

### 覆盖的 10 个小学核心方法（已接入参数化生成器）

| 方法 | 出题变体 |
|---|---|
| 鸡兔同笼 | 已知头/脚求鸡或兔（假设法/抬脚法） |
| 植树问题 | 两端都栽 / 只栽一端 / 两端不栽 / 环形 |
| 和差倍 | 和差、和倍、差倍 |
| 盈亏问题 | 一盈一亏、双盈、双亏 |
| 平均数 | 求平均、已知平均求缺的数 |
| 周期问题 | 余数定位第 N 个 |
| 归一问题 | 先求单一量、归总反求 |
| 工程问题 | 合作时间、反求单独、效率比较 |
| 相遇问题 | 求时间 / 路程 / 一速度 |
| 追及问题 | 求时间 / 路程差 / 一速度 |

| 一元一次不等式 | 七年级 | 解不等式 / 判断方向 |

其余技巧（小学剩余 + 高中全阶段）采用静态题库 + 随机抽题模式，每轮也保证不同组合。

### 学习路径与薄弱点追踪
- 路径化学习：技巧按依赖关系编排，循序渐进
- 通关测试：每个技巧有「闯关」模式，错题自动加入薄弱点
- 薄弱点复习：针对未掌握的题反复练，直至清空
- **返回路径自动定位**：练习完点「返回路径」，自动滚动高亮到刚才练的技巧节点

### 判断题统一样式
2 选项判断题用 ✓/✗ 标记，与 4 选项题风格统一、清晰可辨。

## 技术架构

- **纯前端**：HTML + 原生 JS + CSS，零构建步骤、零运行时依赖
- **零外链**：所有资源本地化，可完全离线运行
- **数据驱动**：`window.TECHNIQUES` 数组定义所有技巧与题目
- **本地存储**：学习进度持久化在 `localStorage`
- **Hash 路由**：单文件应用，部署即用

## 本地运行

无需任何安装，直接用浏览器打开 `index.html` 即可。

或起一个本地静态服务器：

```bash
python -m http.server 8142
# 然后访问 http://127.0.0.1:8142/
```

## 项目结构

```

│   ├── qgen_junior.js # 初中方法参数化出题引擎（15 方法 qgen）
│   └── app.js         # 应用主逻辑（路由、渲染、状态）
└── README.md
```
